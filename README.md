# Atelier Eclat

E-commerce visual de joyeria para Atelier Eclat.

## Ver localmente

```bash
node server.js
```

Abrir:

```text
http://localhost:4173
```

## Publicar en GitHub Pages

1. Subir estos archivos al repositorio.
2. En GitHub, ir a `Settings > Pages`.
3. En `Build and deployment`, elegir `Deploy from a branch`.
4. Seleccionar la rama `main` y carpeta `/root`.
5. Guardar.

La web quedara disponible en:

```text
https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/
```

## Nota

La tienda usa imagenes oficiales enlazadas desde Pandora Espana para los productos mostrados y mantiene identidad visual propia como Atelier Eclat.
